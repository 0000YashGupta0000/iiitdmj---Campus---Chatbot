# IIITDMJ Smart Campus Chatbot 🤖🎓

An intelligent conversational assistant designed to streamline access to campus information at the Indian Institute of Information Technology, Design and Manufacturing (IIITDM), Jabalpur. Developed collaboratively as part of the Electronics and Robotics Society (ERS) initiatives.

## 🚀 Overview
This chatbot leverages Machine Learning and Natural Language Processing to provide students, faculty, and visitors with instant, automated responses. It bridges the gap between the campus community and essential information, handling queries related to academic schedules, administrative procedures, and club activities.

## 🛠️ Tech Stack
* **Language:** Python
* **Core Domains:** Artificial Intelligence, Machine Learning, Natural Language Processing
* **Key Libraries/Frameworks:** [NLTK, TensorFlow, PyTorch, LangChain]

## ✨ Features (In Progress)
* **Campus Navigation:** Quick access to facility details and locations.
* **Academic Assistant:** Information on course schedules and curriculum basics.
* **Club Integrations:** Direct updates from ERS and other campus organizations.
